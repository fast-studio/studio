# FAST STUDIO

FAST STUDIO is an independent studio founded by Nathan Fast. We build and publish apps, websites and games.

[Website](https://byfast.org) · [Games on itch.io](https://byfast.itch.io) · [Reddit](https://www.reddit.com/user/byfastorg/)

## Projects

### 100 MEN

Three peasants. Endless waves. Recruit, merge and equip your army in a browser-based pixel-art auto-battler roguelite.

[![100 MEN — a browser game by FAST STUDIO](https://byfast.org/projects/hundredmen-world.jpg)](https://byfast.itch.io/100-men)

[Play on itch.io](https://byfast.itch.io/100-men) · [Game website](https://100men.byfast.org)

### F•CODE

A visual project workspace for macOS that brings files, previews and coding agents together on one board.

[![F•CODE — a visual coding workspace by FAST STUDIO](https://byfast.org/shop/fcode.jpg)](https://byfast.org/shop/code)

[Explore F•CODE](https://byfast.org/shop/code)

### F•CLIPS

A video app for turning a topic or a long video into short videos.

[Explore F•CLIPS](https://byfast.org/clips)
